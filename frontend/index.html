口径说明

宽松口径（7 项）：单位移动、单位战斗、城市生产、人口增长、科技推进、文化推进、金币增长。逐项看「这一回合有没有动静」，和模型写的那句话没有直接关系。

严格口径：从计划文本里按固定词表抽出兵种（勇士／弓箭手／建造者／开拓者／商人／英雄），核对下一回合该兵种是否移动、造成伤害或从快照消失。只是被打掉血不算，那是别人执行的。

已知偏差：城市、人口两项都只看 pid=0 的第一座城；金币增长几乎恒真，去掉它平均分会从 34% 掉到 23.4%。详情见仓库 README 的「已知问题」。

数据边界：快照里的 units 只有我方的兵，cities 和 players 是全部六家；is_agent 字段全为 false，认我方只能认 pid=0。pid=4 在 91–140 回合缺席，pid=1 在 123–140 缺席。

两种聚合：脚本报的 33.9% 是「通过项 ÷ 总项数」（240/707）；这里显示的 34% 是「先算每回合百分比、再对 101 个回合求平均」。小样本下两者会分开走。
